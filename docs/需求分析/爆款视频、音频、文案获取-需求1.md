# 需求 1：爆款视频、音频、文案获取

## 一句话目标

输入 TikTok / YouTube / Instagram / Facebook 的爆款视频链接，得到：**视频文件、音频文件、识别文案、中文译文**。

## 周期与资源

- 周期：约 3 天
- 主力 GPU：RTX 5070 Ti（备用 2060）
- 依赖网络分流：下载国外平台内容、拉取模型/依赖

---

## 业务说明

用户已有各平台视频链接（长视频或短视频）。需要：

1. 把视频下载到本地
2. 从视频中提取音频
3. 用 ASR（语音转文字）识别出文案并展示
4. 若原文非中文，用 LLM 翻译成中文并展示

---

## 流水线（搭积木顺序）

```
链接 (URL)
  → [download]        → Video
  → [extract_audio]   → Audio
  → [asr]             → Transcript（文本 + 时间戳）
  → [translate]       → Translation（中文）
```

需求 1 的界面/CLI 可以只展示「全文 + 译文」；但 `asr` 积木仍须输出带时间戳的 `Transcript`，以便需求 2 直接复用。

---

## 本需求用到的积木

| 积木 | 输入 | 输出 | 说明 |
| --- | --- | --- | --- |
| `download` | URL + 平台 | `Video` | 支持 youtube / tiktok / instagram / facebook；可按平台拆成子积木，对外统一入口 |
| `extract_audio` | `Video` | `Audio` | ffmpeg 抽音、统一格式 |
| `asr` | `Audio` | `Transcript` | 本地 GPU；片段级文本 + 起止时间 |
| `translate` | `Transcript`（或纯文本） | `Translation` | 非中文 → 中文；已是中文可透传 |
