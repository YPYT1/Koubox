## 🔬 一、核心技术方案深度分析

### 方案 1：**SenseVoice-Small**（🔥 强烈推荐 - ASR 首选）

#### 技术突破

**架构创新：非自回归端到端框架**

```
传统 Whisper（自回归）：
每个 token 依赖前一个 → 串行生成 → 慢

SenseVoice（非自回归）：
并行预测所有 token → 一次输出 → 15 倍速度提升
```

**训练数据规模：**
- **400,000+ 小时**多语言语料
- 涵盖 50+ 语言（开源版支持 5 种：中文、粤语、英文、日文、韩文）

#### 性能数据（实测）

**速度对比：**

| 模型 | 5 分钟英文播客 | 27 分钟中文播客 | 实时倍率 |
|------|---------------|----------------|---------|
| Whisper-Large-v3 (GPU) | 22.5 秒 | 121 秒 | 13.4x |
| **SenseVoice-Small (GPU)** | **1.8 秒** | **9.6 秒** | **169.6x** |
| **SenseVoice-Small (CPU)** | **17.5 秒** | **94 秒** | **17.2x** |

> 来源：[FunASR 官方基准测试](https://funasr.com/en/blog/funasr-vs-whisper-benchmark.html)

**准确度对比（中文）：**

| 模型 | CER (字错误率) | 备注 |
|------|---------------|------|
| Whisper-Large-v3 | 20.02% | 基准 |
| **SenseVoice-Small** | **7.81%** | **提升 2.6 倍** |
| Paraformer-Large | 10.18% | FunASR 另一模型 |

> 来源：[FunASR vs Whisper 真实中文会议音频测试](https://github.com/modelscope/FunASR/discussions/2947)

**日文准确度：**
- 自动添加标点符号（、。）
- Whisper-small 输出无标点，SenseVoice 原生带标点
- 情感识别附加功能（7 类情感：愤怒、快乐、悲伤等）

> 来源：[日文语音识别测试](https://funasr.com/en/blog/japanese-speech-recognition.html)

**粤语（Cantonese）特性：**
```python

# SenseVoice 的优势：
输入：「呢個唔係嘅」
SenseVoice 输出：「呢個唔係嘅」（保留粤语）
```

> 来源：[粤语识别对比](https://funasr.com/en/blog/cantonese-speech-recognition.html)

#### 模型大小与部署

| 版本 | 大小 | 精度 | 适用场景 |
|------|------|------|---------|
| 完整模型 | ~250MB (FP16) | 100% | GPU 服务器 |

| GGUF q4 量化 | ~130MB | 98.5% | 移动设备 |

**关键优势：**
```
✅ 比 Whisper-Small (1.5GB) 小 6 倍，准确度更高
✅ CPU 运行速度超过 Whisper GPU 版本
```


#### 使用方式

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

# 加载模型
model = AutoModelForCausalLM.from_pretrained(
    "Qwen/Qwen3-ForcedAligner-0.6B",
    device_map="cuda"
)
tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen3-ForcedAligner-0.6B")

# 强制对齐
def align_audio_text(audio_path, transcript):
    """
    对齐音频与文本
    
    返回：每个字符/词的起止时间（80ms 精度）
    """
    inputs = tokenizer(transcript, return_tensors="pt").to("cuda")
    
    # 提取音频特征（需要配合 ASR 模型）
    audio_features = extract_audio_features(audio_path)
    
    # 预测时间戳
    outputs = model.generate(
        **inputs,
        audio_features=audio_features,
        max_length=1024
    )
    
    # 解析时间戳
    timestamps = parse_timestamps(outputs)
    
    return timestamps  # [(char, start_ms, end_ms), ...]
```

**实际集成示例：**

```python
# 完整流水线：ASR + 强制对齐
from funasr import AutoModel as FunASRModel
from qwen3_asr import ForgedAligner

# 步骤 1：用 SenseVoice 做初步识别
asr_model = FunASRModel(model="iic/SenseVoiceSmall")
asr_result = asr_model.generate(input="audio.wav")

# 步骤 2：用 Qwen3-ForcedAligner 精准对齐
aligner = ForgedAligner("Qwen/Qwen3-ForcedAligner-0.6B")
aligned = aligner.align(
    audio="audio.wav",
    text="用户提供的原文稿",  # 替代 ASR 结果
    language="ja"
)

# 输出：词级时间戳
for word, start, end in aligned:
    print(f"{word}: {start}ms - {end}ms")
```

#### 技术细节

**非自回归架构优势：**
```
传统对齐方法（如 HMM）：
时间累积 → 长音频容易漂移

Qwen3-ForcedAligner（基于 LLM）：
全局注意力机制 → 5 分钟音频无漂移
```

**内存占用：**
- 模型大小：~1.2GB（0.6B 参数）
- 推理显存：~3GB (FP16)
- 支持量化：INT8 可降至 ~1.5GB 显存

**处理限制：**
- 单次最长：5 分钟音频
- 超过 5 分钟：自动分段处理
- 长音频（>20 分钟）：建议按自然停顿手动切分

> 来源：[ComfyUI Qwen3-ASR 插件文档](https://github.com/shumoLR/Comfyui_SynVow_Qwen3ASR)

### 方案 3：**ctc-forced-aligner + Meta MMS**（🌏 台语专用方案）

#### 核心价值：解决台语（闽南语）对齐难题


**规模：**
- 支持 **1,130 种语言**的语音识别
- 支持 **4,000+ 种语言**的语言识别

**台语支持验证：**

#### 使用方式

**安装：**
```bash

```

**台语对齐示例：**
```python
from ctc_forced_aligner import (
    load_alignment_model,
    generate_emissions,
    preprocess_text,
    get_alignments,
    get_spans
)

# 加载 MMS 模型
alignment_model, alignment_tokenizer, alignment_dictionary = \
    load_alignment_model(
        device="cuda",
        model_name="MahmoudAshraf/mms-300m-1130-forced-aligner",
        lang="nan"  # 台语/闽南语 ISO 639-3 代码
    )

# 提取音频特征
emissions, stride = generate_emissions(
    alignment_model,
    audio_path="taiwanese_audio.wav",
    batch_size=1
)

# 预处理台语文本（汉字表示）
tokens = preprocess_text(
    "這是一句台语例句",  # 用汉字记录的台语
    romanize=True,  # 可选：启用罗马化
    language="nan"
)

# 获取对齐结果
segments, scores, blank_id = get_alignments(
    emissions,
    tokens,
    alignment_dictionary
)

# 转换为时间戳
spans = get_spans(segments, audio_path)

# 输出
for span in spans:
    print(f"{span['label']}: {span['start']:.2f}s - {span['end']:.2f}s")
```

### 3.2 Python 实现核心代码

```python
from enum import Enum
from typing import Optional, List, Tuple
from funasr import AutoModel as FunASRModel
from ctc_forced_aligner import load_alignment_model, get_alignments

class LanguageCode(Enum):
    """支持的语言"""
    CHINESE = "zh"
    JAPANESE = "ja"
    CANTONESE = "yue"
    KOREAN = "ko"
    ENGLISH = "en"
    MINNAN = "nan"  # 台语

class AlignmentMode(Enum):
    """对齐模式"""
    WITH_SCRIPT = "forced_align"  # 有原文，强制对齐
    NO_SCRIPT = "asr_only"        # 无原文，纯识别

class PreciseSrtGenerator:
    """
    新一代精准 SRT 生成器
    
    集成：
    - SenseVoice：日文/中文/粤语/韩文/英文 ASR
    - Qwen3-ForcedAligner：日文/中文强制对齐
    - MMS + ctc-aligner：台语支持
    """
    
    def __init__(
        self,
        use_sensevoice: bool = True,
        use_qwen3_aligner: bool = True,
        device: str = "cuda"
    ):
        self.device = device
        
        # 初始化 SenseVoice（快速 ASR）
        if use_sensevoice:
            self.asr_model = FunASRModel(
                model="iic/SenseVoiceSmall",
                vad_model="fsmn-vad",
                device=device
            )
        
        # 初始化 Qwen3-ForcedAligner（精准对齐）
        if use_qwen3_aligner:
            from qwen3_asr import ForgedAligner
            self.qwen3_aligner = ForgedAligner(
                "Qwen/Qwen3-ForcedAligner-0.6B",
                device=device
            )
        
        # 初始化 MMS + ctc-aligner（台语支持）
        self.mms_model = None  # 按需加载
    
    def generate_srt(
        self,
        audio_path: str,
        script_text: Optional[str] = None,
        language: Optional[LanguageCode] = None,
        output_path: Optional[str] = None
    ) -> dict:
        """
        生成精准 SRT 字幕
        
        Args:
            audio_path: 音频文件路径
            script_text: 可选的原文稿
            language: 语言代码（None 则自动检测）
            output_path: 输出路径
            
        Returns:
            {
                'srt_path': str,
                'segments': List[Segment],
                'language': str,
                'mode': str,
                'quality_score': float
            }
        """
        
        # 步骤 1：语言检测
        if language is None:
            language = self._detect_language(audio_path)
        
        # 步骤 2：选择模式
        mode = AlignmentMode.WITH_SCRIPT if script_text else AlignmentMode.NO_SCRIPT
        
        # 步骤 3：根据语言和模式选择处理管线
        if language == LanguageCode.MINNAN:
            # 台语专用管线
            segments = self._process_minnan(audio_path, script_text)
        
        elif mode == AlignmentMode.WITH_SCRIPT:
            # 有原文：强制对齐
            segments = self._forced_align(
                audio_path,
                script_text,
                language
            )
        
        else:
            # 无原文：纯 ASR
            segments = self._asr_only(audio_path, language)
        
        # 步骤 4：断句优化
        segments = self._optimize_segmentation(segments)
        
        # 步骤 5：导出 SRT
        if output_path is None:
            output_path = audio_path.replace(
                audio_path.split('.')[-1],
                'srt'
            )
        
        self._export_srt(segments, output_path)
        
        # 步骤 6：质量评估
        quality_score = self._assess_quality(segments)
        
        return {
            'srt_path': output_path,
            'segments': segments,
            'language': language.value,
            'mode': mode.value,
            'quality_score': quality_score
        }
    
    def _detect_language(self, audio_path: str) -> LanguageCode:
        """自动检测语言"""
        result = self.asr_model.generate(
            input=audio_path,
            language="auto"
        )
        
        lang_map = {
            'zh': LanguageCode.CHINESE,
            'ja': LanguageCode.JAPANESE,
            'yue': LanguageCode.CANTONESE,
            'ko': LanguageCode.KOREAN,
            'en': LanguageCode.ENGLISH
        }
        
        detected = result[0].get('language', 'zh')
        return lang_map.get(detected, LanguageCode.CHINESE)
    
    def _asr_only(
        self,
        audio_path: str,
        language: LanguageCode
    ) -> List[dict]:
        """
        纯 ASR 模式（无原文）
        使用 SenseVoice 快速转写
        """
        result = self.asr_model.generate(
            input=audio_path,
            language=language.value,
            use_itn=True,
            batch_size_s=60,
            merge_vad=True
        )
        
        segments = []
        for item in result:
            segments.append({
                'text': item['text'],
                'start': item['timestamp'][0] / 1000,  # ms → s
                'end': item['timestamp'][1] / 1000,
                'confidence': item.get('score', 1.0)
            })
        
        return segments
    
    def _forced_align(
        self,
        audio_path: str,
        script_text: str,
        language: LanguageCode
    ) -> List[dict]:
        """
        强制对齐模式（有原文）
        使用 Qwen3-ForcedAligner 精准对齐
        """
        if language in [LanguageCode.CHINESE, LanguageCode.JAPANESE]:
            # 使用 Qwen3-ForcedAligner（最高精度）
            aligned = self.qwen3_aligner.align(
                audio=audio_path,
                text=script_text,
                language=language.value
            )
            
            segments = []
            for word, start_ms, end_ms, confidence in aligned:
                segments.append({
                    'text': word,
                    'start': start_ms / 1000,
                    'end': end_ms / 1000,
                    'confidence': confidence
                })
            
            return segments
        
        else:
            # 降级：用 SenseVoice ASR 结果
            return self._asr_only(audio_path, language)
    
    def _process_minnan(
        self,
        audio_path: str,
        script_text: Optional[str]
    ) -> List[dict]:
        """
        台语（闽南语）专用处理管线
        使用 MMS + ctc-forced-aligner
        """
        if self.mms_model is None:
            # 按需加载 MMS 模型
            from ctc_forced_aligner import load_alignment_model
            self.mms_model, self.mms_tokenizer, self.mms_dict = \
                load_alignment_model(
                    device=self.device,
                    model_name="MahmoudAshraf/mms-300m-1130-forced-aligner",
                    lang="nan"
                )
        
        if script_text:
            # 有原文：强制对齐
            from ctc_forced_aligner import (
                generate_emissions,
                preprocess_text,
                get_alignments,
                get_spans
            )
            
            emissions, stride = generate_emissions(
                self.mms_model,
                audio_path,
                batch_size=1
            )
            
            tokens = preprocess_text(
                script_text,
                romanize=True,
                language="nan"
            )
            
            segments_raw, scores, _ = get_alignments(
                emissions,
                tokens,
                self.mms_dict
            )
            
            spans = get_spans(segments_raw, audio_path)
            
            segments = []
            for span in spans:
                segments.append({
                    'text': span['label'],
                    'start': span['start'],
                    'end': span['end'],
                    'confidence': span.get('score', 1.0)
                })
            
            return segments
        
        else:
            # 无原文：用 MMS 做 ASR
            # （实际中 MMS ASR 接口较复杂，这里简化）
            # 建议降级用中文模型
            return self._asr_only(audio_path, LanguageCode.CHINESE)
    
    def _optimize_segmentation(
        self,
        segments: List[dict],
        max_chars: int = 18
    ) -> List[dict]:
        """
        断句优化：合并短句，拆分长句
        适配短视频字幕规范（12-18字/行）
        """
        optimized = []
        current_segment = None
        
        for seg in segments:
            text = seg['text'].strip()
            if not text:
                continue
            
            if current_segment is None:
                current_segment = seg.copy()
            
            # 检查是否需要合并
            combined_text = current_segment['text'] + text
            
            if len(combined_text) <= max_chars:
                # 合并
                current_segment['text'] = combined_text
                current_segment['end'] = seg['end']
            else:
                # 保存当前，开启新段
                optimized.append(current_segment)
                current_segment = seg.copy()
        
        if current_segment:
            optimized.append(current_segment)
        
        return optimized
    
    def _export_srt(
        self,
        segments: List[dict],
        output_path: str
    ):
        """导出标准 SRT 文件（剪映兼容）"""
        with open(output_path, 'w', encoding='utf-8-sig') as f:  # UTF-8 BOM
            for i, seg in enumerate(segments, 1):
                start = self._format_srt_time(seg['start'])
                end = self._format_srt_time(seg['end'])
                text = seg['text']
                
                f.write(f"{i}\n")
                f.write(f"{start} --> {end}\n")
                f.write(f"{text}\n")
                f.write("\n")
    
    def _format_srt_time(self, seconds: float) -> str:
        """格式化 SRT 时间戳"""
        ms = int(seconds * 1000)
        hours = ms // 3_600_000
        minutes = (ms % 3_600_000) // 60_000
        secs = (ms % 60_000) // 1000
        millis = ms % 1000
        
        return f"{hours:02d}:{minutes:02d}:{secs:02d},{millis:03d}"
    
    def _assess_quality(self, segments: List[dict]) -> float:
        """评估字幕质量"""
        if not segments:
            return 0.0
        
        score = 100.0
        
        # 检查时长分布
        for seg in segments:
            duration = seg['end'] - seg['start']
            
            if duration < 0.3:  # 过短
                score -= 2
            elif duration > 8.0:  # 过长
                score -= 1
        
        # 检查间隙
        for i in range(len(segments) - 1):
            gap = segments[i + 1]['start'] - segments[i]['end']
            if gap > 1.0:  # 大间隙
                score -= 0.5
        
        return max(0.0, min(100.0, score))


# 使用示例

    )
```
