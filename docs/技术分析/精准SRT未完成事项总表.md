# 精准 SRT 未完成事项总表

更新时间：2026-09-09

本文是精准 SRT 当前工作的统一状态记录。它把已经完成、仍待执行、暂不实施和被新实现取代的内容分开，避免把历史实验结果误写成当前生产能力。

## 当前结论

精准 SRT 的生产链路已经具备四语声学对齐、词级时间处理、气口分段、语言边界约束、语速诊断、受限术语纠正和最终 SRT 导出能力。日文分词底座已经从 Janome 改为 `SudachiPy + SudachiDict-core`，但 Sudachi 改造后的完整产品回归和便携包复验仍待执行。

当前新增的 CUDA 日文边界模型只是实验基线。它在独立生成验证集上的 F1 为 `0.606060606060606`，尚未经过人工金标准和真实生产样本验证，因此没有接入生产分段器。

中文可以作为日语边界训练的辅助基准，但当前项目还没有中日句子对齐数据、中文语义边界标注和映射后的日语金标准。后续必须让中文提供语义停顿信号，同时让日语 Sudachi 边界和日语人工标注决定最终切点。

## 已完成并有记录的事项

### 精准 SRT 基础链路

- 模式 A 使用音频和用户文案进行声学对齐，最终正文锁定为用户文案的展示归一化结果。
- 模式 B 不在 worker 推理阶段读取参考文案；参考文案只用于测试阶段计算错误率。
- 模式 B 支持关闭、自动和强制三种语速策略。
- 低置信度复识别只接受满足一致性和置信度门槛的候选。
- 修正后的文本重新对齐原始音频，变速音频的时间戳不直接写入最终 SRT。
- 最终字幕执行正时长、递增时间轴、最大时长和语言字符/单词上限检查。
- 现有 Python、core、类型检查和构建结果已经在历史验证文档中记录为通过；这些记录对应当时的代码状态，不能代替当前 Sudachi 改造后的重新验证。

### 日文分词改造

- `python/src/koubox_runtime/precise_srt_segmentation.py` 已使用 Sudachi 词边界构造日语短语单元，并在超限时按 C → B → A 逐级细分。

## 当前仍未完成的事项

### 1. 建立人工金标准

状态：未完成，优先级最高。

当前训练数据来自自动生成的日文边界资料，不能证明字幕边界符合真实口播习惯。需要建立人工确认的数据集，至少包含：

- 原始日文文本；
- 音频或可复核的时间轴；
- 人工确认的日语字幕边界；
- 每个边界的停顿、语法完整性和可读性说明；
- 可选的中文翻译及中文自然短语边界。

人工金标准必须覆盖正常语速、快速语速、专业术语、复合词、助词链、句尾表达和跨句停顿。没有这套数据，模型 F1 只能作为训练过程指标。

完成条件：至少形成独立训练、验证、测试三部分；每部分均保存原文、边界标签、数据来源和审校记录；在测试集上报告边界 Precision、Recall、F1、边界偏移和字幕结构合法率。

### 2. 建立中文语义基准并映射到日语

状态：未开始。

目标是让用户可以用中文理解和审核语义停顿，再把语义信号映射到日语安全边界。中文边界不能直接按字符位置复制到日语，必须经过中日短语对齐。

计划数据结构：

```json
{
  "japanese": "この製品は現場で長く使えます",
  "chinese": "这款产品可以在现场长期使用",
  "chinese_segments": ["这款产品", "可以在现场", "长期使用"],
  "japanese_segments": ["この製品は", "現場で", "長く使えます"]
}
```

实现约束：

1. 中文只提供语义停顿和短语完整性信号。
2. 中日对齐器必须输出每个中文片段对应的日语字符区间或日语词区间。
3. 映射结果必须投影到 Sudachi 提供的合法日语边界。
4. 最终训练标签和生产切点仍以日语边界为准。
5. 对齐失败时直接记录失败样本，进入人工复核，不使用默认位置替代。

完成条件：中日对齐数据通过人工抽检；报告中文边界到日语合法边界的映射成功率、映射偏移和无法映射比例；证明加入中文信号后在独立日语测试集上有可重复改善。
