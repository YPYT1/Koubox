# 实施决策（2026-08-21）

- 前端：React 19 + TypeScript。
- 通信：Electron 主进程启动仅监听 `127.0.0.1` 的本地 HTTP 服务；preload 注入短生命周期鉴权令牌，渲染进程不直接获得 Node 权限。
- ASR：避免 Electron 原生 addon ABI/CUDA 兼容风险。主进程以按任务拉起的本地命令行运行器方式适配 ASR；模型目录由 runtime 检测，运行器实现可替换。
- 翻译：仅使用本地模型运行器，不调用云 API。
- 对齐：先保持 `Text + Transcript -> Transcript` 契约。初始实现提供基于 ASR 时间范围的已知文案分段基线；实际“精准对齐”后续替换为本地强制对齐运行器，不改变 UI 或 API 契约。
- TTS：当前范围明确不做，不建立 TTS 配置和流水线。
