---

## 1. 产品模型：工具箱，不是单页流水线

整个软件 = **工具箱壳** + **可插拔工具**。

- 需求 1「爆款素材获取」、需求 2「精准 SRT」都是**一个工具**
- 以后加功能 = 注册新工具，不改壳的信息架构
- 左侧栏长期稳定：**常驻入口 + 已打开区**（界面不显示「固定」二字）

---

## 2. 布局结构（浅色 + 草图）

整体 **浅色风格**。信息架构对齐草图：

```
┌──────────────────────────────────────────────────────────────┐
│ 标题栏                                                        │
├───────────────┬──────────────────────────────────────────────┤
│ 工具箱（可拖宽）│           [ 搜索入口 ………… ]                   │
│ 工具箱/模型/设置│                                               │
│ 已打开（子菜单）│   工具项铺开网格：图标 + 名字 + 简介            │
│               │   （仅铺开；窄屏自动减列）                        │
└───────────────┴──────────────────────────────────────────────┘
```

| 区域 | 说明 |
| --- | --- |
| 左侧「工具箱」栏 | 工具箱 / 模型与环境 / 设置 + 已打开；**不显示「固定」标签**；右边缘可拖动调宽（约 180–420px） |
| 主区顶 | 「搜索入口」过滤工具 |
| 主区内容 | **固定铺开网格**；每项含图标、名字、简介 |

视觉：浅色；已去掉最左窄「工具栏」；不做竖向列表模式。

### 2.1 常驻入口（永远在，无「固定」标题）

| 项 | 作用 |
| --- | --- |
| 工具箱 | 首页：卡片目录 + 搜索结果；从此处「打开」工具 |
| 模型与环境 | ASR **可选路径**；GPU **自动检测**（含显存总量/已用/剩余）；yt-dlp/ffmpeg 内置不展示 |
| 设置 | 输出目录、语言等全局项 |

### 2.2 已打开（动态）

- 用户从工具箱打开某个工具 → 出现在「已打开」
- **当前聚焦的工具**：展开其**子菜单**（该工具内部页面）
- 可关闭（×）；关闭后若正在看它，则回到「工具箱」
- 多工具可同时开着，类似浏览器多标签，但是竖排在侧栏

### 2.3 搜索与布局

- 搜索在主区顶部（草图「搜索入口」），过滤工具目录；回车打开首个匹配
- **仅铺开网格**（无列表切换）；窄屏自动减列
- 每项保留 **图标 + 名字 + 简介**

## 3. 信息架构（给开发用）

```ts
// 工具注册（主进程或前端配置均可，建议 shared）
type ToolManifest = {
  id: string
  name: string
  tag?: string
  description: string
  menus: { id: string; label: string; route: string }[]
}

// 会话状态（前端）
type Session = {
  opened: { toolId: string; activeMenuId: string }[]
  focus: { type: 'fixed'; id: 'home' | 'models' | 'settings' }
        | { type: 'tool'; id: string }
}
```

| 概念 | 说明 |
| --- | --- |
| `ToolManifest` | 静态：有哪些工具、各有哪些子页 |
| `opened[]` | 动态：用户打开了谁 |
| `focus` | 当前主区渲染谁；工具聚焦时侧栏展开其子菜单 |

扩展新工具：只加一条 `ToolManifest` + 对应页面组件，侧栏逻辑不用改。

---

## 4. 与业务流水线的关系

- **壳 / 工具箱 UI**：只管打开哪个工具、哪个子页（渲染进程）  
- **积木 / 流水线**：在 Electron 主进程的 `packages/core`；工具页通过 IPC/API 调 `pipelines/req1` 等  

不要把「下载、ASR」写进侧栏组件里。

---

## 5. 交互要点（验收可对）

1. 固定三项始终可见  
2. 打开工具后，「已打开」出现该项，并可展开子菜单  
3. 切换固定项（如设置）时，已打开列表仍保留（不强制卸载工具）  
4. 关闭工具会从已打开移除  
5. 搜索能过滤；从卡片/搜索都能打开  

---

## 6. 实现建议（Electron 前端）

- 布局：左 `Sidebar` + 右 `Workspace`  
- 路由建议：  
  - `/home`、`/models`、`/settings`  
  - `/tools/:toolId/:menuId`  
- 「已打开」用前端状态（或 localStorage 恢复上次会话）  
- 工具列表可从主进程 IPC（如 `tools:list`）拉取，便于以后热更新清单
