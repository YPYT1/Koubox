## 1. 桌面与工程

| 名称 | 用途 | 备注 |
| --- | --- | --- |
| **Electron** | 本地软件外壳（主进程 + 渲染进程） | **已定**；业务在主进程 |
| **TypeScript** | 主进程业务 + 渲染进程 UI | 主要开发语言 |
| **Node.js（LTS）** | 开发与构建（打包后用户可不装） | 已定 |
| **pnpm** | 包管理 / monorepo | 默认；Bun 仅在完整可用时再考虑 |
| **React 19.2** | 前端页面 | 待锁一个（或 Vue） |
| **Tailwind CSS** | 渲染进程 UI 样式 | **已定**；仅前端，主进程不用 |
| **electron-vite** 或 **electron-forge** | 开发/构建脚手架 | 建仓时定一个 |
| **electron-builder** | Windows 安装包 | 待锁具体配置 |
| **Git** | 版本管理 | — |

**不再需要**：Rust / rustup、Tauri、独立 Node 侧车进程。

## 2. 媒体下载与处理（随软件打包）

| 名称 | 用途 | 备注 |
| --- | --- | --- |
| **yt-dlp** | 下 YouTube / TikTok / IG / FB 等视频 | **不重写源码**；主进程封装调用；**打进安装包** |
| **ffmpeg** | 抽音、转码、统一音频格式 | **打进安装包**；界面不做配置项 |

---

## 3. 语音 / 模型相关

| 名称 | 用途 | 备注 |
| --- | --- | --- |
| **ASR 模型**（本地） | 语音 → 文本 + 时间戳 | 用户**可选路径**；具体型号待锁（如 Whisper 系等） |
| **ASR 运行时 / 绑定** | 在 Electron 主进程调用模型 | 待锁：ONNX / whisper.cpp 子进程 / 其它可 GPU 方案 |
| **NVIDIA 驱动 + CUDA**（按选型） | GPU 推理 | 主力 5070 Ti；需能读显卡名与显存 |
| **翻译（LLM API 或本地）** | 非中文 → 中文 | 需求 1；待锁具体服务/模型 |
| **TTS**（需求 2，可选） | 文案 → 音频 | 可跳过（用户自备音频）；待锁 |
| **对齐能力**（需求 2） | 已知文案 + 音频 → 时间轴 | 待锁具体算法/库 |

---

## 4. 运行时要做的能力（自研模块）

| 技术点 | 说明 |
| --- | --- |
| **runtime 注册表** | ASR 路径配置；不散落在各积木里 |
| **GPU 自动检测** | 显卡名、是否可用、**显存总量 / 已用 / 剩余** |
| **积木化流水线** | download → extract_audio → asr → translate 等（主进程） |
| **SRT 导出** | `Transcript` → 标准 `.srt` |
| **IPC 契约** | 渲染进程 ↔ 主进程；类型放 `packages/shared` |
| **工具箱 UI** | 浅色；可拖宽侧栏；工具铺开网格 |

---

## 5. 开发机建议准备

1. 安装：**Node LTS、pnpm、Git**（**无需 Rust**）  
2. 准备好可调用的：**yt-dlp、ffmpeg**（开发期可先放 `vendor/`）  
3. 装好：**NVIDIA 驱动**；按 ASR 方案补 CUDA / 运行库  
4. 准备一份 **ASR 模型** 到本机目录（软件里选路径）  
5. 网络：国内外分流（下平台内容、拉依赖/模型）
