## 第一轮阻断项

1. `precise_srt.run()` 与 `koubox_runtime.__main__` 会对同一次异常输出两次 error 帧。
2. 零时长字幕按字符比例造时间，违背声学对齐约束。
3. 超长原子短语缺少“只在 stable-ts 完整词边界兜底拆分”的实现。
4. 便携包 postflight 未检查 `stable_whisper`、Janome、Faster-Whisper 和 `precise_srt`。
5. 两个新增测试文件受 `.gitignore` 影响，存在交付漏失风险。
6. 尚未完成真实 GPU、日文 10 条与四语数据验收。

## 处理决定

- 保持已确认的产品模式、接口和 UI 方向不变。
- 错误协议改为一次失败只发送一帧。
- 零时长词并入相邻真实声学区间，不按字符比例分配时间。
- 超长短语仅在 stable-ts 已对齐词边界拆分；单个对齐词本身超限时明确失败。
- 多速率替换使用词索引映射回原始标点文本，避免重复词误替换。
- 增加 portable import/SHA/缓存检查，显式纳入精准 SRT 测试文件。
- 完成修复与真实运行后恢复同一审查流程，直至 `VERDICT: APPROVED`。
