## 1. 本阶段目标

在精准 SRT 产品化之后，补齐发布前工程缺口，并把打包校验拆成可维护钩子，保证**整个桌面端**（不仅是 SRT）在便携包里可运行。

## 2. 已完成

### 精准 SRT / Worker

- `/pipelines/req2` 使用 `assertLocalSpeechMediaPath` + `existsSync`，与其他媒体管线一致。
- `createWorkerTaskError` 透传 `PRECISE_SRT_FAILED` 等协议错误码到 `taskError`。
- `runWorker` 增加按操作类型的超时：`precise_srt` 60 分钟、`asr` 30 分钟、`separate` 45 分钟。
- Worker 非零退出时从 stdout/stderr 解析错误帧或 `code` 字段，不再一律落成无码 `PIPELINE_FAILED`。
- `runWorker` 等待 stdout 结束后再处理退出码，避免 Windows 上 close 早于 stdout 的竞态。
- 桌面端复制 SRT 复用 `@koubox/shared` 的 `transcriptToSrt`（含 UTF-8 BOM）。

### 共享契约

- `transcriptToSrt` / `formatSrtTime` 抽到 `packages/shared/src/srt.ts`，core 与 UI 共用。

### 打包

- `scripts/pack-portable.ps1` 改为调用 `scripts/pack/hooks/*`。
- `scripts/pack/manifests/pack-manifest.json` 作为 ffmpeg、VC++、Python 清单单一来源。
- `after-pack.cjs` 从 manifest 读取 VC++ DLL，并复制到 `vendor/ffmpeg/bin`。
- 预检/后检覆盖：ffmpeg 全文件 + 冒烟、venv site-packages、CUDA 原生库、import 探测、`demucs`（人声分离 / 爆款素材）。

### 测试

- 新增 `packages/core/test/req2-hardening.test.ts`：API 400、错误码透传、超时、`parseWorkerFailure` 协议解析。
