## 2. 背景与输入

当前需求 2 的模式 A 由 `packages/core/src/align.ts` 将用户文案映射到 ASR chunk 时间，包含编辑距离和按字符比例分配，并非声学强制对齐。模式 B 直接导出 Faster-Whisper chunk，缺少词级置信度、受限纠错、重新对齐和气口语义分段。

实验项目已经形成两条独立路线：

```text
模式 A：用户文案 → stable-ts/Faster-Whisper 声学对齐 → regroup → 展示去符号
模式 B：无文案 ASR → 低置信度复识别 → 受限术语纠错 → 原音频重对齐 → regroup
```

产品必须支持中文、英文、日文、韩文。模式 B 不得在推理阶段读取参考文案。

## 3. 已确认决策

- 精准 SRT 页面增加任务级语言选择：自动、中文、英文、日文、韩文。
- 模式 B 增加任务级语速策略：关闭、自动、强制多速率；默认自动。
- 术语只使用随版本发布的内置受限规则，不提供用户编辑入口。
- 用户侧只增加最终 SRT，不生成 raw SRT 或审计 JSON；诊断写任务记录和日志。
- stable-ts 2.19.1 的 MIT 源码快照复制进仓库并固定哈希，不从实验目录动态导入。
- 四语功能一致；中日韩使用 CER，英文同时使用 WER 与 CER。
- FLEURS 只作为测试数据，不进入发布包。

## 4. 问题分析

1. `alignKnownText()` 只使用 ASR 段边界，无法锁定文案中每个词的声学位置。
2. `asr.py` 只返回 chunk 级文本、起止时间，丢失 word probability。
3. 当前 SRT 导出会再次按长度比例切分长 chunk，不能替代音频气口和词边界分段。
4. 快速语音样本的 CER 随语速增加明显恶化；固定对全部音频变速会增加耗时并可能损害正常语速。
5. 日文算法使用 Janome，直接扩展到四语会产生错误词边界，必须按语言定义原子单元。

## 5. 需求规格

### 模式 A

- 用户文案保留标点进入声学对齐。
- 最终正文必须与用户文案展示归一化后 100% 一致。
- final cue 必须正时长、严格递增、最长 3 秒，并满足各语言展示上限。

### 模式 B

- 初次识别保留原始标点、完整词时间和 probability。
- 可疑片段前后扩展 0.6 秒，使用 1.0、0.90、0.80 三速率候选。
- 至少两路候选一致且平均概率提升不少于 0.10 才自动替换；精确上下文规则可直接替换。
- 纠正文本必须回到原始音频重新对齐，变速时间戳不得写入 SRT。
- `off` 不变速；`auto` 只在快速且低置信度时触发；`force` 绕过语速门槛但仍只处理可疑片段。

### 分段

- 硬气口 `>=0.45s`，中气口 `0.22-0.45s`，软气口 `0.12-0.22s`。
- 中文、日文最多 14 个有效字符；韩文最多 18 个；英文最多 8 个单词且不超过 42 个可见字符。
- 日文使用 Janome 短语；中文使用完整对齐词与虚词吸附；英文使用完整单词并避免孤立功能词；韩文使用完整空格词组。

## 6. 实现方案

### Python

- 固定上游 `stable_whisper` 2.19.1 源码与 MIT LICENSE，并记录文件 SHA256 清单。
- 新增 `koubox_runtime.precise_srt`，封装模型加载、模式 A/B、四语分段、术语、语速检测与多速率复识别。
- `koubox_runtime.__main__` 增加 `precise_srt` operation；通用 `asr` operation 保持不变。
- Python response 返回最终 segments、检测语言和精简 diagnostics。

### TypeScript 与 UI

- `/pipelines/req2` 接收 `language` 与 `speechRateMode`。
- TaskSnapshot 持久化请求语言、检测语言、语速模式和是否触发多速率。
- `TaskManager.executeRequirementTwo()` 改为一次调用 `precise_srt` worker，移除需求 2 的 `alignKnownText()` 调用。
- RequirementTwoPage 在两种模式显示语言选择，仅在无文案显示语速策略。
- TS 继续负责写带 UTF-8 BOM 和末尾换行的最终 SRT。

### 打包

- Python 锁文件加入 Janome 与 vendored stable-ts 所需依赖。
- 便携包 postflight 校验 `stable_whisper`、`janome`、`faster_whisper` 和 `koubox_runtime.precise_srt` 可导入。
