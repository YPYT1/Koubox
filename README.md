# 口播匣 / Koubox

本地 GPU 创作者工具箱：视频素材获取（下载、抽音、识别、翻译）与精准 SRT 对齐。

## 已初始化能力

- Electron + React 19 桌面壳
- 主进程启动的受保护本地 HTTP API（仅 `127.0.0.1`）
- 工具箱、模型与环境、全局设置三页
- 本地模型目录完整性检查、GPU 状态检查、FFmpeg / yt-dlp 可用性检查
- 需求 1 / 需求 2 的界面和货物契约骨架
- 标准 SRT 导出与已知文案对齐的基础算法单元测试

## 启动

```bash
pnpm install
pnpm dev
```

当前模型目录默认为仓库中的 `model/`，也可在「全局设置」中修改。

## 本地推理运行器

模型文件和推理运行器分开管理。设置页中的 ASR / 翻译运行器命令为空时，应用会保持可运行，但会拒绝启动真实媒体任务，避免生成伪结果。后续可接入可执行的 whisper.cpp 或 Python/CUDA 命令行运行器；核心 TypeScript 契约无需改变。
